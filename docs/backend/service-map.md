# Backend Service Map

| 项目 | 架构 | 主要职责 | 高风险边界 |
| --- | --- | --- | --- |
| center-platform | 单模块 MVC | 站点、组织、账号、权限、字典、配置、文件 | 权限、站点上下文、公共 DTO、文件契约 |
| center-gateway | WebFlux Gateway | 路由、鉴权、登录态、请求上下文 | 白名单、Header/Token、阻塞调用、路由兼容 |
| center-point | COLA 多模块 | 积分规则、账户明细、发放、预算、预警 | 账务精度、业务号幂等、预算并发、规则 SQL |
| center-vip | COLA 多模块 | 等级、成长值、成长任务、权益、资产同步 | 等级状态机、跨期批处理、同步补偿、缓存失效 |
| center-manage | 单模块 MVC | 活动画布、客群标签协作、触达、报表、资格 | 状态机、批次游标、消息重试、跨数据源查询 |
| center-mall | 单模块 MVC | 商城活动、商品、订单、优惠券、内容运营 | 库存预算、支付退款、资格、缓存、异步补偿 |
| center-chain | COLA 多模块 | 供应链、权益、订单履约、核销、售后、结算 | 库存、履约状态、退款、结算幂等、跨服务一致性 |
| xxl-job | Admin + Core | 任务注册、调度、触发、回调、重试、日志 | 调度协议、权限、重复触发、回调恢复、数据库迁移 |

静态调用关系由各项目画像记录。真实运行拓扑和配置中心覆盖需在目标环境确认。
