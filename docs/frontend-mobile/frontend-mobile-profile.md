# Frontend Mobile Profile

移动端项目包括移动 Web、H5、WebView、活动页和消费端旅程。常见信号包括移动 UI 框架、viewport/rem 转换、touch-first 布局、safe-area、游客/登录链路、支付分享能力和 legacy WebView 目标。

TeamAI 只提供平台级边界：移动导航与返回、身份初始化、列表刷新状态、真实容器验证、兼容与 polyfill。具体 UI 框架、设计稿口径、API 别名、storage 工具、站点参数和微信/App Bridge 行为必须从当前仓库读取。

涉及 OAuth、支付、分享签名、定位、媒体或内嵌容器时，静态检查不能替代真实域名、账号、设备和宿主环境验证。
