# Backend Contracts And Security

- 修改 Controller、Feign、`client` 模块、DTO、枚举、错误码、路径、Topic、任务名或共享模型前，列出已知生产者、消费者、兼容策略、发布顺序和回滚影响。
- 参数校验、统一响应和异常转换沿用目标服务现有实现；不得为了测试便利绕过鉴权、站点/租户隔离、数据权限、签名、限流或防重放。
- SQL 必须参数化绑定并兼容目标项目实际数据库方言；运行数据库、Nacos 覆盖项和生产配置无法从仓库证明时标记为待环境确认。
- Feign 调用必须明确连接/读取超时、失败语义和降级行为。Fallback 不得把关键失败伪装成成功，也不得无边界重试。
- 日志使用参数化字段，在单一责任点记录完整异常；禁止输出 Token、Cookie、口令、密钥、完整客户标识、完整请求响应或动态 SQL 敏感参数。
- 外部回调、开放接口、内部接口与后台/C 端入口保持现有身份边界；新增入口必须说明调用方、认证方式和重放风险。
