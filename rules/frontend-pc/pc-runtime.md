# Frontend PC Runtime

- 适用于桌面管理、运营、配置和数据工作台，不按业务仓库名区分规则。
- UI 框架、自动导入、路径别名、权限指令、分页 Hook 和组件目录必须从当前仓库配置与相邻代码确认；不得把某个 PC 仓库的名称或目录约定提升为全部 PC 项目的硬规则。
- 菜单、路由和敏感操作使用同一权限来源；按钮隐藏不能替代服务端鉴权。
- 表格、表单、批量操作、导入导出和持久侧栏等桌面交互应复用当前仓库已有抽象。
- 浏览器基线以当前仓库 browserslist、构建 target 和交付环境为准；缺失时才把 Chrome 90+、Edge 90+、Safari 15+ 作为待确认的团队参考线。
- 若仓库存在 AI、可视化、编辑器或其他独立边界脚本，按仓库实际脚本执行，不把其目录名和命令复制到其他 PC 仓库。
