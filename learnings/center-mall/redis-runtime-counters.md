# Center Mall Redis 运行态计数器

`center-mall` 的抽奖与达标领好礼已经形成 Redis 运行态计数器模式：审批后预热，在线链路用 Lua/原子操作扣减，数据库保存镜像，异常通过回补和强对账恢复。

后续扩展库存或预算能力时必须保持：

- key 与玩法隔离并集中定义；金额统一为整数最小单位。
- Redis 原子判断决定是否可继续，数据库镜像不能反向放大权威值。
- 事务回滚、下游失败和 MQ 发送失败都有明确回补或同步回落。
- 读路径可按既有语义回源，写路径不能在并发下用过期镜像重复初始化。
- 重建任务校验活动范围、版本和领取有效期，避免覆盖在线新数据。
