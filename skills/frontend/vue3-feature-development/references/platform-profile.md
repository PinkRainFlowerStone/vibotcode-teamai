# Platform Profile

## PC Web

- 适用于桌面管理、运营、配置和数据工作台。
- 从当前仓库识别 UI 框架、权限来源、表格/表单模式、分页 Hook、自动导入、浏览器目标和验证命令。
- 不把另一个 PC 仓库的组件目录、别名、AI/可视化边界或脚本名当作共享事实。

## Mobile Web

- 适用于移动 Web、H5、WebView、活动页和消费端旅程。
- 从当前仓库识别 UI 框架、viewport/rem 口径、列表刷新模式、身份初始化、storage、legacy target、支付分享和宿主桥接。
- 不套用 PC 的桌面组件、分页 Hook、权限指令或浏览器基线。

## Routing

- 由用户明确说明、README、依赖、布局模型、构建 target、viewport/legacy 配置和交互模式共同识别运行端。
- 平台画像只提供运行端边界；API 命名、别名、组件目录、环境变量和验证命令始终以当前仓库为准。
- 原生或跨端小程序不使用本 Skill，改用 `mini-program-development`。
