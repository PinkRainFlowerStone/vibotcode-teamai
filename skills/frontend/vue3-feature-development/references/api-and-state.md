# API And State

- 延续项目已有 `A_` API 命名和 request 封装，不从组件直接创建新的 Axios 客户端。
- 页面发起交互，Hook 承接复用逻辑，API 层发请求，Store 只承接跨页面共享状态。
- 接口字段来源不明时暂停补全，不写多字段回退。
- 请求 loading 在 `finally` 复位；错误数据、空态、禁用和重复提交行为跟随相邻业务并保持显式。
- 权限语义在菜单、路由、按钮间保持一致，敏感操作使用项目已有权限能力。
- 两个后台复用 `usePagination`；H5 复用 `useListRefresh` 或相邻的 Vant 列表状态，不跨平台强推同一抽象。
- 本地存储通过项目已有工具处理；站点、登录、游客态和回跳信息不得新增平行 key 或清理流程。
