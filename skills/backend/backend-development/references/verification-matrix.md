# Verification Matrix

| 变更类型 | 最小验证 |
| --- | --- |
| Controller/DTO | 合法参数、校验拒绝、鉴权/站点边界、统一响应 |
| Feign/外部接口 | 成功、超时、空响应、业务失败、fallback/降级语义 |
| 数据写入/事务 | 成功、回滚、重复请求、并发条件更新、远程部分失败 |
| Redis/锁/缓存 | key 隔离、锁超时与释放、缓存失效、重建覆盖、Redis 不可用 |
| MQ/回调 | 重复、乱序、重试、毒消息、消费部分成功、补偿重跑 |
| XXL-JOB/定时任务 | 重复触发、多实例竞争、分页游标、失败恢复、重试上限 |
| 金额/积分/库存/预算 | 单位、精度、边界值、原子扣减、不足、回滚/对账 |
| 状态机 | 合法迁移、非法迁移、并发旧状态条件、超时与补偿 |

验证命令必须来自目标仓库实际 POM、文档和测试目录。需要数据库、Redis、MQ、Nacos 或调度中心时，先确认隔离环境，不对生产执行验证。
